# Run a Node

Congratulations, now that you have installed PrometheusChain, it's time to run it.

In this section, we'll guide you through running a PrometheusChain node across local, devnet, testnet, and production environments.

## Networks

Choose the network you want to run your node on:

-   **PrometheusChain local-single** - Run one fast local developer node
-   **PrometheusChain devnet** - Connect to the public resettable development network
-   **PrometheusChain testnet** - Connect to the public stable test network
-   **[Private testnets](/run/private-testnets)** - Set up and run private test networks

## Configuration & Monitoring

Learn how to configure and monitor your node:

-   **[Configuration](/run/configuration)** - Configure your node using PrometheusChain node configuration
-   **[Monitoring](/run/monitoring)** - Set up logs, metrics, and observability
