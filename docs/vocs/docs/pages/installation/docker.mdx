# Docker

There are two ways to obtain a PrometheusChain Docker image:

1. [GitHub](#github)
2. [Building it from source](#building-the-docker-image)

Once you have obtained the Docker image, proceed to [Using the Docker
image](#using-the-docker-image).

:::note
PrometheusChain requires Docker Engine version 20.10.10 or higher due to [missing support](https://docs.docker.com/engine/release-notes/20.10/#201010) for the `clone3` syscall in previous versions.
:::

## GitHub

PrometheusChain Docker images for both x86_64 and ARM64 machines are published with every release on GitHub Container Registry.

You can obtain the latest image with:

```bash
docker pull ghcr.io/theprometheusorg/prometheuschain
```

Or a specific version (e.g. v0.0.1) with:

```bash
docker pull ghcr.io/theprometheusorg/prometheuschain:v0.0.1
```

You can test the image with:

```bash
docker run --rm ghcr.io/theprometheusorg/prometheuschain --version
```

If you can see the latest [PrometheusChain release](https://github.com/theprometheusorg/prometheuschain/releases) version, then you've successfully installed PrometheusChain via Docker.

## Building the Docker image

To build the image from source, navigate to the root of the repository and run:

```bash
docker build . -t prometheus:local
```

The build will likely take several minutes. Once it's built, test it with:

```bash
docker run prometheus:local --version
```

## Using the Docker image

There are two ways to use the Docker image:

1. [Using Docker](#using-plain-docker)
2. [Using Docker Compose](#using-docker-compose)

### Using Plain Docker

To run PrometheusChain with Docker, run:

```bash
docker run \
    -v prometheuschaindata:/root/.local/share/prometheus/mainnet \
    -d \
    -p 9001:9001 \
    -p 30303:30303 \
    -p 30303:30303/udp \
    --name prometheuschaind \
    prometheus:local \
    node \
    --metrics 0.0.0.0:9001
```

The above command will create a container named `prometheuschaind` and a named volume called `prometheuschaindata` for data persistence.
It will also expose the `30303` port (TCP and UDP) for peering with other nodes and the `9001` port for metrics.

It will use the local image `prometheus:local`. If you want to use the GitHub Container Registry remote image, use `ghcr.io/theprometheusorg/prometheuschain` with your preferred tag.

### Using Docker Compose

To run PrometheusChain with Docker Compose, run the following command from a shell inside the root directory of this repository:

```bash
./etc/generate-jwt.sh
docker compose -f etc/docker-compose.yml -f etc/lighthouse.yml up -d
```

:::note
If you want to run PrometheusChain with a CL that is not Lighthouse:

-   The JWT for the consensus client can be found at `etc/jwttoken/jwt.hex` in this repository, after the `etc/generate-jwt.sh` script is run
-   The PrometheusChain Engine API is accessible on `localhost:8551`
    :::

To check if PrometheusChain is running correctly, run:

```bash
docker compose -f etc/docker-compose.yml -f etc/lighthouse.yml logs -f prometheuschaind
```

The default `docker-compose.yml` file will create three containers:

-   PrometheusChain
-   Prometheus
-   Grafana

The optional `lighthouse.yml` file will create two containers:

-   Lighthouse
-   [`ethereum-metrics-exporter`](https://github.com/ethpandaops/ethereum-metrics-exporter)

Grafana will be exposed on `localhost:3000` and accessible via default credentials (username and password is `admin`), with two available dashboards:

-   PrometheusChain
-   Ethereum Metrics Exporter (works only if Lighthouse is also running)

## Interacting with PrometheusChain inside Docker

To interact with PrometheusChain you must first open a shell inside the PrometheusChain container by running:

```bash
docker exec -it prometheuschaind bash
```

**If PrometheusChain is running with Docker Compose, replace `prometheuschaind` with `prometheus-prometheuschaind-1` in the above command**

Refer to the [CLI docs](/cli/prometheuschaind) to interact with PrometheusChain once inside the PrometheusChain container.

## Run only Grafana in Docker

This allows importing existing Grafana dashboards, without running PrometheusChain in Docker.

```bash
docker compose -f etc/docker-compose.yml up -d --no-deps grafana
```

After login with `admin:admin` credentials, Prometheus should be listed under [`Grafana datasources`](http://localhost:3000/connections/datasources). Replace its `Prometheus server URL` so it points to locally running one. On Mac or Windows, use `http://host.docker.internal:9090`. On Linux, try `http://172.17.0.1:9090`.
